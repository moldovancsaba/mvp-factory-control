# General Knowledge

This page is the shared knowledge index for the MVP Factory portfolio.

## Canonical Truths

- `mvp-factory-control` is the central control repository for the portfolio
- the GitHub Project board is the source of truth for delivery state
- product implementation belongs in product repositories unless the work is explicitly control-plane work
- `apps/mvp-factory-control` is internal control-plane tooling inside this repository

## What Belongs Here

- cross-project lessons
- recurring delivery patterns
- shared product navigation knowledge
- glossary terms
- portfolio-level operating knowledge

## What Does Not Belong Here

- product-only implementation notes
- temporary scratch notes
- release-specific notes that belong in a product repo

## Shared Vocabulary

- portfolio: the set of managed repositories and products
- control repository: `mvp-factory-control`
- product repository: the repo where a product is implemented
- internal control app: the app in [`apps/mvp-factory-control`](../apps/mvp-factory-control)
- evidence: the verifiable change summary and validation attached to a delivery issue
