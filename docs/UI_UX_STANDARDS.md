# UI/UX Standards

These are shared UI/UX rules across the portfolio.

## Global Rules

- no baked-in style systems that prevent reuse or theming
- no hardcoded content where structured content/config belongs
- no inaccessible interaction patterns
- no desktop-only assumptions
- no placeholder polish presented as complete UX
- no product-specific visual doctrine hidden in a shared standard unless it is truly shared

## Layout Grammar

- use consistent spacing systems
- keep typography hierarchy explicit
- design responsively by default
- make information density intentional

## Styling

- prefer tokens, variables, and shared primitives
- avoid scattered one-off style values
- avoid locking layout decisions into one component when they should be reusable
